一、Java 的基本写法

核心原则

先有类，再有变量和方法。

Java 是强类型语言，所有代码都必须写在类里面。不能像 JavaScript 那样在文件最外层直接写变量或函数。

// 正确写法public class Demo {    int a = 1;    void test() {}}

文件与类的关系

  • 一个 .java 文件中可以写多个类

  • 最多只能有一个 public 类，且该类的名字必须和文件名一致

  • 如果文件名为 Run.java，那么 public class Run {} 是合法的

变量 / 属性写法

修饰符 类型 名字 = 值;final String str = "aaa";private String sort = "bbb";int age = 18;

每个变量定义时都必须明确类型。

本节要点

  1. 所有代码都必须写在类里面

  2. 类是 Java 程序的基本构成单元

  3. 一个 .java 文件中，与文件名同名的 public 类只能有一个

  4. Java 写法可总结为：修饰符 + 类型 + 名字

二、运行 Java 程序

入口方法

Java 程序从 public static void main(String[] args) 开始执行。

public class Start {  public static void main(String[] args) {    System.out.println("Hello Java");  }}

三、包的概念和使用

核心规则

  • 同一个包内的类可以直接使用

  • 不同包中的类，需要通过 import 引入

  • package 名称必须和文件夹路径一致

  • import 后面跟完整类名，或使用 * 批量引入

package com.demo.start;import com.demo.service.Calculator;public class Start { }
