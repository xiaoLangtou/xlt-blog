- 所有组件均使用 `<script setup lang="ts">` 语法，并通过 `defineOptions({ name: '...' })` 显式声明组件名称。
- 组件对外暴露的数据结构通过 TypeScript interface 定义（如 `ExceptionData`、`ResultPageProps`），并使用 `withDefaults(defineProps<...>(), {...})` 设置默认值。
- 状态管理统一通过 Pinia store 组合式函数获取（`useUserStore`、`useSettingStore`），并通过 `storeToRefs` 保持响应式引用。
- 模板中使用 Tailwind CSS 原子类进行布局与样式，复杂动画与主题适配则写在 scoped `<style lang="scss">` 块中。
- 国际化文案统一通过 `$t()` 或 `useI18n()` 的 `locale` 访问，语言枚举来自 `@/enums/appEnum.LanguageEnum`。
