本模块以 Vue 单文件组件（SFC）为单位组织，每个子目录对应一个独立可复用的布局或全局组件，统一通过 `index.vue` 作为入口并配合 `defineOptions({ name })` 声明组件名。
- 布局组合层：`art-header-bar` 聚合面包屑、搜索、全屏、语言切换、通知、聊天、设置按钮，并内嵌 `ArtWorkTab` 和 `ArtNotification`；`art-menus` 下按菜单形态拆分为 `art-sidebar-menu`（左侧/双列）、`art-horizontal-menu`（顶部）、`art-mixed-menu`（顶左混合），各自通过 `widget/*` 子组件渲染子菜单项。
- 设置面板层：`art-settings-panel` 采用 Provider + Composables 架构，`SettingsProvider.vue` 暴露上下文，`composables/` 下按职责拆分配置（useSettingsConfig）、状态（useSettingsState）、事件处理（useSettingsHandlers）、滚动监听（useSettingsScrollSpy）、标签页（useSettingsTabs）；`widget/` 下为纯展示型设置行组件（ToggleRow、PrefGroup、ThemeModePicker 等）。
- 辅助布局组件：`art-col-page`（分割面板，含 README 文档）、`art-work-tab`（多标签页，内置滚轮/触摸滑动与右键菜单）、`art-global-component`（动态加载启用的全局组件）、`art-fast-enter`、`art-fireworks-effect`、`art-screen-lock`、`art-notification`、`art-chat-window`、`art-breadcrumb` 等。
- 依赖方向：组件仅向上依赖 `@/store/modules/*`（setting/user/menu/worktab）、`@/hooks/*`、`@/config`、`@/enums/appEnum` 及第三方库（Element Plus、VueUse、vue-i18n、vue-router），不反向依赖业务页面。
