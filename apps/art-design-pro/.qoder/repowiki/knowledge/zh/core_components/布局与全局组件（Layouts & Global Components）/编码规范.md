- 每个组件目录以 `index.vue` 为唯一入口，并在 `<script setup>` 中使用 `defineOptions({ name: 'ArtXxx' })` 显式声明组件名。
- 组件内部状态与行为通过 `composables/` 下的 useXxx 函数进行逻辑拆分，视图层仅负责渲染与事件派发。
- 菜单类组件统一通过 `filterMenuItems` 递归过滤 `meta.isHide` 的隐藏项，并对父节点做“子集全隐藏则父隐藏”的处理。
- 设置项配置采用数据驱动：在 `useSettingsConfig.ts` 中以数组形式声明 key/label/type/handler/headerBarKey，再由通用渲染组件（SettingRow、PrefGroup 等）根据配置动态生成 UI。
- 样式采用 scoped SCSS 并通过 `:deep(.el-*)` 覆盖 Element Plus 默认样式，同时使用 CSS 变量（如 `--default-bg-color`、`--theme-color`）实现主题切换。
- 跨组件通信优先使用 Pinia store（setting/user/menu/worktab）+ `storeToRefs` 读取响应式状态，局部弹窗/下拉状态通过本地 ref 管理。
