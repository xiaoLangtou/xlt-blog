- 每个组件通过 defineOptions({ name: 'ArtXxx' }) 显式声明组件名称，便于调试面板识别。
- 组件采用 `<script setup lang="ts">` 语法，Props 通过 TypeScript interface 定义并使用 withDefaults 设置默认值。
- 样式统一使用 Tailwind CSS 原子类（如 flex-cc、text-g-500、border-g-300），避免自定义 CSS。
- 组件内依赖的外部功能通过导入 hooks/utils 的方式获取（如 useCommon、normalizeIcon），不直接操作 DOM 或第三方库。
