本模块为 Vue 3 单文件组件集合，每个子目录对应一个独立组件（art-back-to-top、art-logo、art-svg-icon），均通过 `<script setup lang="ts">` 实现 Composition API。
- art-svg-icon：基于 `@iconify/vue` 的 Icon 组件封装，通过 `normalizeIcon` 工具统一处理 Iconify 名称与后端 Lucide 格式，使用 `inheritAttrs: false` 配合 `useAttrs` 透传 class/style。
- art-logo：纯展示型组件，通过 props.size 控制尺寸，默认 36px，样式由 computed 生成。
- art-back-to-top：交互型组件，监听 `#app-main` 滚动位置，超过 300px 阈值时显示，依赖 `@/hooks/core/useCommon` 的 scrollToTop 方法。
- 组件间无直接依赖，均向上层暴露命名选项（defineOptions name）以便调试识别。
