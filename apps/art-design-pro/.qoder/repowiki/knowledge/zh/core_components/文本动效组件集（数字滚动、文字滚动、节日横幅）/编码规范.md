- 每个功能子目录仅包含一个 `index.vue` 单文件组件，职责单一且自包含。
- Props 统一通过 TypeScript 接口（如 `CountToProps`、`TextScrollProps`）+ `withDefaults(defineProps<...>(), {...})` 声明默认值。
- 事件通过 `defineEmits<...>()` 以类型化方式定义，并在组件生命周期中通过 `emit` 触发。
- 外部命令式 API 通过 `defineExpose<...>()` 显式暴露方法与时态属性，供父组件调用。
- 动画与 DOM 操作统一使用 `@vueuse/core` 的组合式函数（`useTransition`、`useRafFn`、`useElementSize` 等），避免手写原生定时器或 requestAnimationFrame。
- 数值参数在进入计算前通过 `validateNumber` / `clamp` 等工具函数进行边界校验与范围限制，非法值记录 `console.warn` 并回退默认值。
