本模块为纯展示型子组件集合，按功能拆分为三个独立子目录，每个子目录仅含一个 `index.vue` 单文件组件（SFC），无共享逻辑层。
- `art-count-to/index.vue`：基于 `@vueuse/core` 的 `useTransition` + `TransitionPresets` 实现数字从当前值到目标值的缓动动画，通过 `defineExpose` 暴露 `start/pause/reset/stop/setTarget` 等命令式 API 及 `isRunning/isPaused/currentValue/targetValue/progress` 只读状态。
- `art-text-scroll/index.vue`：使用 `useRafFn` 驱动 `requestAnimationFrame` 循环，结合 `useElementSize` 与 `useElementHover` 完成尺寸测量、溢出检测、鼠标悬停暂停，并通过克隆内容节点实现水平/垂直方向的无缝循环。
- `art-festival-text-scroll/index.vue`：薄封装层，依赖全局 `settingStore` 和 `useCeremony` hook 控制显示，内部直接复用 `ArtTextScroll` 组件。
依赖方向单向向下：festival 组件依赖 text-scroll；count-to 独立不依赖其他两个组件。所有组件均通过 `withDefaults` + TypeScript 接口声明 props，通过 `defineEmits` 定义事件，遵循 Vue 3 Composition API 规范。
