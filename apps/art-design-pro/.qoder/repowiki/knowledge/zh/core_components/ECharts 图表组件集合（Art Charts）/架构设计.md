每个图表类型独立为一个子目录（如 art-bar-chart、art-line-chart 等），每个目录仅包含一个 index.vue 单文件组件，遵循一致的架构模式：
- 模板层：使用 ref="chartRef" 绑定容器 div，通过 :style 设置 height，v-loading 控制加载态。
- 组合式逻辑：所有组件均通过 `useChartComponent` hook 统一管理 ECharts 实例生命周期、响应式数据监听、空数据判断与选项生成，各组件只需实现 `checkEmpty`、`watchSources` 和 `generateOptions` 三个回调。
- 样式与主题：通过 `useChartOps()` 获取全局图表配置（颜色、字体、尺寸等），通过 `getCssVar` 读取 Element Plus CSS 变量，支持明暗主题切换（isDark）。
- 依赖方向：组件只依赖上层 hooks（@/hooks/core/useChart）、工具函数（@/utils/ui）、类型定义（@/types/component/chart）和 ECharts（@/plugins/echarts），不互相引用。
