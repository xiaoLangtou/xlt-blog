- 每个组件通过 `defineOptions({ name: 'ArtXxx' })` 显式声明组件名称，便于调试与错误追踪。
- 表单类组件（art-form、art-search-bar）统一使用 `withDefaults(defineProps<...>(), {})` 定义 props 默认值，并通过 `defineModel` 实现 v-model 双向绑定。
- 表单项渲染采用 `componentMap` 映射 + `<component :is="...">` 动态组件方式，同时支持通过 `render` 字段或插槽覆盖默认渲染逻辑。
- 提交/搜索输出统一经过 `sanitizeOutputValue` 函数清洗空值（空字符串、空数组、空对象、空富文本），但保留 0 和 false 等有效值。
- 组件对外暴露方法统一通过 `defineExpose` 暴露，如 validate、reset、getOutput、exportData、getEditor 等，供父组件通过 ref 调用。
- 样式采用 scoped SCSS 编写，结合 Tailwind CSS 原子类进行布局，CSS 变量（如 `--theme-color`、`--system-input`）用于主题适配。
