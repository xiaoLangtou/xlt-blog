本模块以独立 Vue 单文件组件（SFC）形式组织，每个子目录对应一个可复用组件，统一通过 `defineOptions({ name: '...' })` 注册组件名。核心组件包括：
- `art-form` 与 `art-search-bar`：两者共享相同的表单项配置模型（`FormItem`/`SearchFormItem`）、组件映射表 `componentMap`、响应式列宽计算（依赖 `@/utils/form/responsive` 的 `calculateResponsiveSpan`）、以及统一的值清洗策略（`sanitizeOutputValue`），均通过 `defineModel` 实现双向绑定并暴露 `validate/reset/getOutput` 方法。
- `art-excel-import` 与 `art-excel-export`：分别封装 xlsx 库的读取与写入能力，前者通过 `FileReader` + `XLSX.utils.sheet_to_json` 解析上传文件，后者通过 `XLSX.utils.json_to_sheet` + `FileSaver` 生成下载文件，均通过事件（`import-success/error`、`export-*`）与父组件通信。
- `art-wang-editor`：封装 `@wangeditor/editor-for-vue`，支持工具栏自定义、图片上传（含自定义上传模式）、全屏监听与实例方法暴露。
- `art-drag-verify`：纯原生鼠标/触摸事件实现的滑块验证码，通过 CSS 变量驱动样式，使用 `defineExpose` 暴露 `reset` 方法。
- `menu-icon-picker`：基于 `lucide-vue-next` 的图标选择器，结合 `normalizeIcon` 工具处理命名空间。
- `art-button-more` 与 `art-button-table`：轻量级操作按钮，前者集成权限控制（`useAuth`），后者提供预设类型（add/edit/delete/view/more）。
所有组件遵循 Composition API + `<script setup>` 风格，无跨组件内部依赖，仅通过 props/emits/events 与外部交互。
