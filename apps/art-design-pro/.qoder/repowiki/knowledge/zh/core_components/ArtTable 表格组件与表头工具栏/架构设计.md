模块由两个独立 Vue 单文件组件构成：`art-table/index.vue` 是核心表格组件，对外暴露 `columns`、`pagination`、`paginationOptions` 等 props，内部通过 `v-bind="mergedTableProps"` 透传所有 ElTable 属性与事件，并扩展了全局序号列（`type='globalIndex'`）、展开行（`type='expand'`）、自定义列插槽（`useSlot`/`useHeaderSlot`）等能力；`art-table-header/index.vue` 是表格头部工具栏，通过 `layout` 字符串（如 `'search,refresh,size,fullscreen,columns,settings'`）控制按钮显隐，使用 `defineModel('columns')` 双向绑定列可见性。两个组件共享 `@/store/modules/table` 中的 Pinia store（`isBorder`、`isZebra`、`tableSize`、`isFullScreen`、`isHeaderBackground`），并通过 `useTableHeight` hook + `useResizeObserver` 实现表格高度自适应。样式方面，`art-table/style.scss` 使用 scoped SCSS + `:deep()` 覆盖 Element Plus 默认样式，`art-table-header` 使用 Tailwind CSS 原子类。依赖方向单向向下：组件 → Pinia store → hooks → Element Plus。
