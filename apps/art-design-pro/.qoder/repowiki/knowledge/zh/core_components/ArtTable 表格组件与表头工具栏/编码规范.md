- 组件通过 `withDefaults(defineProps<...>(), {...})` 声明 props 并提供默认值，同时使用 `defineEmits<{...}>()` 进行 TypeScript 类型化的事件声明。
- 表格列渲染采用 `col.type === 'globalIndex' | 'expand' | default` 的分发模式，通过 `cleanColumnProps` 剥离插槽控制字段后再传给 ElTableColumn。
- UI 状态（边框、斑马纹、表格尺寸、全屏、表头背景）统一从 Pinia store 的 `useTableStore` 读取，props 优先级高于 store 值（`props.xxx ?? store.xxx`）。
- 响应式 DOM 操作统一通过 `useResizeObserver` + `requestAnimationFrame` 避免 ResizeObserver loop 警告，并在 `watchEffect({ flush: 'post' })` 中执行副作用。
- 组件名称通过 `defineOptions({ name: 'ArtTable' | 'ArtTableHeader' })` 显式声明，便于调试和 DevTools 识别。
