- 每个组件在 `<script setup>` 顶部通过 `defineOptions({ name: 'ArtXxx' })` 显式声明组件名称
- Props 统一以 TypeScript interface 定义，并使用 `withDefaults(defineProps<Props>(), {...})` 提供默认值
- 组件内样式采用 scoped CSS 结合 Tailwind 原子类，CSS 变量通过 `v-bind('props.xxx')` 动态绑定
- 需要与外部交互的组件通过 `defineExpose` 暴露方法（如 `show`/`hide`），而非直接操作 DOM
