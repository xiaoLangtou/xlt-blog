本模块由两个并列子目录组成：`others/` 存放非基础但常用的功能型组件（右键菜单 `art-menu-right`、水印 `art-watermark`），`widget/` 存放可复用的 UI widget（图标按钮 `art-icon-button`）。每个组件均为单文件 Vue 3 组件（`.vue`），采用 `<script setup lang="ts">` + TypeScript 接口定义 props，并通过 `defineOptions({ name: 'ArtXxx' })` 显式声明组件名。组件之间无内部依赖，均通过 props 暴露配置项，使用 `withDefaults` 设置默认值；`art-menu-right` 通过 `defineExpose` 暴露 `show/hide/visible` 方法供父组件调用，`art-watermark` 则从 Pinia store（`useSettingStore`）读取全局水印开关状态。样式全部使用 scoped CSS 配合 Tailwind 类名，动画通过 Vue `<Transition>` 实现。
