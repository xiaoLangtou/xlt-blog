每个子目录对应一个独立 Vue 单文件组件（index.vue），命名遵循 ArtXxxCard 规范并通过 defineOptions 注册 name。组件内部统一使用 Tailwind CSS 类名和 art-card 基础样式容器；图表类组件（折线、柱状、环形）通过 hooks/core/useChart 中的 useChartComponent 抽象 ECharts 渲染逻辑，watchSources 声明依赖 props 变化，generateOptions 返回 EChartsOption。非图表类组件直接组合 ElProgress、ElImage、ElScrollbar、ElTimeline 等 Element Plus 组件。所有组件通过 withDefaults(defineProps<...>()) 定义 Props 默认值，事件通过 defineEmits 暴露给父组件，无跨组件通信或共享状态。
