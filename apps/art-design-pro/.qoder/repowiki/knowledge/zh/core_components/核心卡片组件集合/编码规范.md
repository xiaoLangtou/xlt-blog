- 每个组件以 index.vue 为入口，使用 defineOptions({ name: 'ArtXxxCard' }) 显式注册组件名。
- Props 通过 TypeScript interface 定义并在 withDefaults(defineProps<...>(), {...}) 中设置默认值。
- 事件通过 defineEmits<{ (e: 'xxx', payload): void }>() 进行类型化声明。
- 图表类组件统一调用 useChartComponent hook，传入 props、checkEmpty、watchSources 和 generateOptions 来生成 EChartsOption。
- 模板中使用 Tailwind CSS 原子类配合 art-card 基础容器类，保持视觉一致性。
- 数值动画类组件（如进度、计数）在 onMounted 生命周期中启动 requestAnimationFrame 动画，并通过 watch 监听 props 变化重新触发。
