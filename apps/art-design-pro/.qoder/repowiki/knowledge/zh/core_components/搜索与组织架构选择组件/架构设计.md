本模块包含两个独立的 Vue 3 单文件组件：
- `search/index.vue`（ArtSearchCard）：以 `<template>` + `<script setup lang="ts">` 实现，通过 `defineProps<Props>()` 声明 keyword、filterItems、filterValues 等 props，使用 computed 双向绑定 update:keyword 与 update:filterValues，并通过 search/reset 事件向上层暴露查询行为；筛选面板支持 select/input/date/daterange 四种内置类型及自定义 slot，标签展示通过 filterLabelMap 将 value 映射为 label。
- `org-selector/index.vue`（OrgSelector）：封装在 el-dialog 中，左侧为部门树+人员列表，右侧为已选标签面板，搜索与选择逻辑下沉到 composable `useOrgSelector`（位于 `@/hooks/core/useOrgSelector`），数据加载通过 `@/api/org-selector` 中的 fetchGetDeptChildren/fetchGetDeptEmployees/fetchSearchOrg 等接口完成，并使用 deptCache Map 缓存部门节点。
- 依赖方向：组件 → hooks（状态管理）→ api（HTTP 请求）→ Element Plus / lucide-vue-next 图标库，无跨组件耦合。
- `search.html` 是纯静态演示页，与 Vue 组件一一对应但不参与构建。
