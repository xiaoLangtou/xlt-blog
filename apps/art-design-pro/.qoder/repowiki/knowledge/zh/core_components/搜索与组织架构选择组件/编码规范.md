- 组件统一使用 `<script setup lang="ts">` 配合 `withDefaults(defineProps<Props>(), {...})` 声明 props 默认值，并通过 `defineEmits` 定义类型化事件。
- 表单双向绑定通过 computed getter/setter 触发 `update:*` 事件（如 keywordModel、filterValues），保持单向数据流。
- 筛选项通过 `FilterItem` 配置数组声明（key/label/type/placeholder/options/span），由模板 v-if 分支渲染对应 El* 组件，新增类型需在模板与 activeFilterTags 计算属性中同步处理。
- 复杂状态逻辑抽离到 composable（如 useOrgSelector），组件仅负责 UI 组装与事件转发，避免在单文件中堆砌业务逻辑。
- 异步数据加载统一使用 try/catch 包裹并调用 ElMessage.error 提示错误，同时维护 loading 状态变量控制 UI。
