模块采用「一文件一业务域」的扁平结构：每个 `.ts` 文件对应一个后端资源域（auth、user、dept、role、menu、dict、post、api-manage、casbin、logger、cache、org-selector），所有文件仅依赖 `@/utils/http` 提供的 request 实例，不相互引用，依赖方向单向向下。
- `index.ts` 作为聚合入口，通过 `export *` 重新导出各子模块，供上层组件按需引入。
- 每个接口函数以 `fetch` 前缀命名（如 `fetchLogin`、`fetchGetUserList`），使用 TypeScript 泛型 `<Api.X.Y>` 标注请求参数与响应类型，类型定义来自全局 `Api.*` 命名空间。
- 数据转换集中在接口层内完成（如 `auth.ts` 中的 `mapUserInfo` 将后端 IUserInfo 映射为前端 UserInfo），保持调用方无需关心后端字段差异。
- HTTP 方法通过 `request.get/post/put/del` 区分，URL 遵循 `/模块/动作` 风格（如 `/user/list`、`/casbin/permission-list`）。
