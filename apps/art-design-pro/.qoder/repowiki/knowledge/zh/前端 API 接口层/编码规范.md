- 接口函数统一以 `fetch` 开头命名（如 fetchLogin、fetchGetUserList、fetchAddUser），并通过命名导出暴露。
- 所有 HTTP 调用均通过 `import request from '@/utils/http'` 获取，禁止直接使用 axios 或其他网络库。
- 请求与响应类型通过 TypeScript 泛型 `<Api.X.Y>` 标注在函数签名上，确保前后端类型契约。
- URL 路径遵循 `/模块名/动作` 的 RESTful 风格，CRUD 操作分别对应 get/post/put/del 四种方法。
- 后端数据结构到前端结构的转换逻辑放在接口层内部（如 mapUserInfo），对外只暴露转换后的结果。
