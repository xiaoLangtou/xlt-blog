- 入口 `index.ts` 通过 `createPinia()` 创建全局 store 实例，并注册 `pinia-plugin-persistedstate` 插件，使用 `StorageKeyManager` 生成 `sys-v{version}-{storeId}` 格式的版本化存储键，实现跨版本数据迁移。
- 业务状态按领域拆分为 `modules/` 下的独立文件：`user.ts`（登录态、令牌、语言、搜索历史）、`setting.ts`（主题、菜单布局、界面开关）、`menu.ts`（动态菜单与路由移除函数）、`table.ts`（表格样式偏好）、`worktab.ts`（多标签页生命周期与 KeepAlive 缓存）。
- 每个模块通过 `defineStore('xxxStore', () => {...}, { persist: { key, storage } })` 声明式定义，状态以 Vue `ref`/`computed` 组织，方法统一在 return 对象中暴露。
- 模块间存在明确依赖方向：`user.ts` 依赖 `setting.ts`、`worktab.ts`、`menu.ts`；`worktab.ts` 依赖 `router` 和类型定义；其他模块保持低耦合，仅通过 Pinia 的 `useXxxStore()` 互访。
- 所有持久化均通过 `localStorage` + JSON 序列化完成，登出时由 `user.logOut` 集中清理相关状态与路由缓存。
