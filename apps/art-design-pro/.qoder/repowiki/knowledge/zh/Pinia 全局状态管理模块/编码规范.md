- 每个 Store 模块使用 `defineStore('xxxStore', () => {...}, { persist: { key: 'xxx', storage: localStorage } })` 的组合式 API 风格定义，状态用 `ref`，派生值用 `computed`。
- 状态变更统一通过具名方法（如 `setUserInfo`、`setLoginStatus`、`setMenuOpen`）修改 ref，而非直接赋值，保持可追踪性。
- 模块间通过 `useXxxStore()` 获取其他 Store 实例进行跨模块状态访问，避免直接 import 模块内部变量。
- 需要持久化的 Store 在第二个参数中声明 `persist` 配置，key 采用简短英文标识（user/setting/table/worktab），storage 固定为 `localStorage`。
- 复杂业务逻辑（如登出、标签页关闭）集中在单个方法内串联多个副作用操作（清空状态、清理缓存、路由跳转），保证原子性。
