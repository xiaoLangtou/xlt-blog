- 路由配置统一使用 `AppRouteRecord` / `AppRouteRecordRaw` 类型定义，并通过 `meta.title`、`isHideTab` 等元信息控制渲染行为。
- 动态路由通过 `RouteRegistry.register()` 一次性注册，并在 `unregister()` 中批量移除，避免重复注册导致的路由冲突。
- 全局守卫采用函数式导出（`setupBeforeEachGuard` / `setupAfterEachGuard`）配合模块级状态变量管理生命周期，而非直接修改 router 实例。
- 异步操作统一通过 TanStack Query 的 `queryClient.fetchQuery` 发起，并使用 `createMenuQueryKey` 生成缓存键。
- 错误处理遵循统一模式：捕获异常后关闭 loading、记录日志、跳转到 `Exception500` 或 `Exception404` 路由，并通过 `isUnauthorizedError` 区分 401 场景。
