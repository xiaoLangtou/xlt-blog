模块以 `index.ts` 为入口，通过 `createWebHashHistory` 创建 Vue Router 实例并挂载静态路由，随后在 `initRouter` 中注册 `beforeEach` 与 `afterEach` 全局守卫。

- 路由配置分层：`routes/staticRoutes.ts` 定义无需鉴权的公共路由（登录、403/404/500、iframe），`routes/asyncRoutes.ts` 聚合 `modules/` 下的业务路由模块（dashboard/system/result/exception），由 `modules/index.ts` 统一导出为 `routeModules`。
- 核心能力集中在 `core/` 子目录，采用类封装职责分离：`RouteRegistry` 负责动态路由的注册/移除与去重；`ComponentLoader` 处理组件懒加载；`RouteValidator` / `RouteTransformer` 负责路由配置校验与转换；`IframeRouteManager` 管理 iframe 路由生命周期；`MenuProcessor` / `RoutePermissionValidator` 处理菜单解析与权限校验。
- 守卫逻辑拆分到 `guards/beforeEach.ts`（登录态检查、动态路由注册、权限验证、根路径重定向、错误兜底）和 `guards/afterEach.ts`（滚动置顶、NProgress 关闭、loading 清理），通过模块级状态变量（`routeInitInProgress`、`routeInitFailed`、`pendingLoading`）防止并发与死循环。
- 依赖方向单向：守卫 → core 类 → 外部 store/api/utils，不反向依赖路由配置，保证核心逻辑可复用。
