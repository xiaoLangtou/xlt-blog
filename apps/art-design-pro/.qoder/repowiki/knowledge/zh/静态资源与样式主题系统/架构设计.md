模块按资源类型划分为三个子目录：`images/` 按业务域（avatar、ceremony、common、draw、lock、login、settings/*、svg、user）组织图片资源；`styles/core/` 通过 `index.scss` 统一入口聚合 reset、app、system-manage、el-ui、dark、router-transition、theme-change、theme-animation、custom-dialog 等核心样式片段，形成分层清晰的样式装配链；`svg/` 仅包含可复用的 SVG 字符串常量（如 loading.ts 导出四点旋转 SVG）。样式采用 SCSS + CSS Variables 驱动主题切换，通过 html 的 `.dark` 类与 `--theme-color`、`--default-box-color` 等 CSS 变量实现亮/暗主题无缝切换，Element Plus 样式通过 el-light.scss/el-dark.scss 分别覆盖。
