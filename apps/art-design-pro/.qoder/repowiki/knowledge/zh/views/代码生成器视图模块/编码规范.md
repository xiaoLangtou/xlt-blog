- 每个功能子目录仅放一个 index.vue 作为路由入口，并通过 defineOptions({ name: 'GenXxx' }) 声明组件名用于路由注册。
- 占位页面统一使用 ElCard + ElEmpty 组合展示「页面开发中，敬请期待」的骨架结构，保持视觉一致性。
- 模板脚本统一使用 `<script setup lang="ts">` 语法，组件内状态以 ref/computed 管理，函数采用具名 function 声明。
- 表格类页面通过 TanStack Table 的 useVueTable + ColumnDef 定义列，并使用 FlexRender 渲染单元格内容，状态通过 onXxxChange 回调同步到本地 ref。
