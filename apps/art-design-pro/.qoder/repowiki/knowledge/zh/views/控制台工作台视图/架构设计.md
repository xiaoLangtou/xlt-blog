采用单入口组件 + 子模块的扁平结构：`index.vue` 作为页面容器，通过 `<script setup>` 直接导入 `modules/` 下的 7 个独立 Vue SFC（card-list、active-user、sales-overview、new-user、dynamic-stats、todo-list、about-project），并使用 Element Plus 的 `ElRow`/`ElCol` 栅格系统按 sm/md/lg 断点组织布局。各子模块均为无状态展示型组件，内部数据以 `reactive` 声明的本地数组驱动，不依赖外部 store 或 API 调用，模块间通过 props 或事件通信的边界清晰，依赖方向单向指向 index 聚合层。
