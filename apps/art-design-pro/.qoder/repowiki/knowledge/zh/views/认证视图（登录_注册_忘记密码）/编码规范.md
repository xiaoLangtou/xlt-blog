- 每个页面使用 `<script setup lang="ts">` 配合 `defineOptions({ name: '...' })` 声明组件名称，并通过 `ref`、`reactive`、`computed` 组织响应式状态。
- 表单统一使用 Element Plus 的 `ElForm` + `ElFormItem` + `ElInput` 组合，并通过 `v-model.trim` 绑定输入值，验证规则集中在 `rules = computed<FormRules>(...)` 中定义。
- 所有用户可见文案通过 `vue-i18n` 的 `$t('xxx.key')` 获取，不直接硬编码字符串。
- 页面布局遵循「左侧 `LoginLeftView` + 右侧 `AuthTopBar` + `auth-right-wrap` 表单容器」的统一结构，样式通过 `@import '../login/style.css'` 共享。
- 表单提交前调用 `formRef.value.validate()` 进行校验，成功后设置 `loading = true`，请求完成后在 `finally` 中重置 loading 状态。
- 语言切换时通过 `watch(locale, () => { formKey.value++ })` 强制重建表单以刷新国际化文案。
