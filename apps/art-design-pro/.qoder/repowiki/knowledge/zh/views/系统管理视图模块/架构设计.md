该模块采用按业务域划分的目录结构，每个子目录（如 menu、role、user、dept、dict 等）代表一个独立的管理页面，遵循统一的组织模式：
- 根级 `index.vue` 作为页面入口，负责数据获取、状态管理和事件编排
- `modules/` 子目录存放页面内可复用的子组件（对话框、搜索框、面板、Tab 等），通过相对路径导入
- 样式采用 SCSS 模块化，复杂页面（如 menu、role）将样式抽离到同级的 `.scss` 文件中并通过 `<style src="./index.scss">` 引用
- 列表类页面统一使用 `useTable` hook（来自 `@/hooks/core/useTable`）封装表格的增删改查、分页、列配置和搜索逻辑
- 详情类页面（menu、role）采用左右分栏布局：左侧树/列表 + 右侧详情面板，通过事件冒泡实现父子组件通信
- API 调用集中在 `@/api/*` 模块中，视图层仅负责组装参数和展示结果，错误处理由 http 工具统一拦截
