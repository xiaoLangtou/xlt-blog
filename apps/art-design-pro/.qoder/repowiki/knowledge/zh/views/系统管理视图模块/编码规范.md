- 每个页面通过 `defineOptions({ name: 'xxx' })` 显式声明组件名称，便于调试和路由注册
- 列表页统一使用 `useTable` hook 管理表格状态，通过 `core.apiFn` 指定 API 函数，`columnsFactory` 定义列配置，`transform.dataTransformer` 处理响应数据
- 弹窗组件通过 `v-model` 双向绑定可见性，并使用 `type` 字段区分新增/编辑模式，提交成功后通过事件回调通知父组件刷新数据
- 删除操作统一使用 `ElMessageBox.confirm` 二次确认，成功时通过 `ElMessage.success` 提示，失败时由 http 工具统一处理错误
- 子组件放在所在页面的 `modules/` 目录下，通过相对路径 `./modules/xxx.vue` 导入，保持页面内组件的局部作用域
- 异步请求采用 try/catch 包裹 loading 状态，在 finally 中重置 loading，错误交由上层统一处理
