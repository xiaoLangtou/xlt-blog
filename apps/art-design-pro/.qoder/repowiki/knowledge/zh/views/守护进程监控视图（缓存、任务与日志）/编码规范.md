- 每个页面均为单文件组件，顶部注释说明用途，并通过 `defineOptions({ name: '...' })` 显式声明组件名。
- 数据请求统一封装在 `@/hooks/queries` 中的 useXxxQuery hooks，视图层仅消费 `isLoading`、`data`、`refetch` 等响应式属性。
- 列表类页面采用 `searchForm` + `appliedSearch` 双表单模式，搜索参数经 computed 合并后传入查询 hook，支持分页与重置。
- UI 布局以 `ElCard` 包裹内容区域，配合 `art-full-height`、`art-table-card` 等通用 class 保持风格一致。
