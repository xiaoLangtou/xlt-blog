该模块为纯展示型视图层，按功能拆分为三个子目录：`cache/index.vue` 通过 `useCacheInfoQuery` hook 拉取 Redis INFO 数据并以统计卡片+表格形式展示；`job-manage/index.vue` 当前为占位页，预留 Quartz 管理入口；`logs/index.vue` 使用 `ArtSearchBar`、`ArtTableHeader`、`ArtTable` 等通用组件配合 `useLogListQuery`/`useLogDetailQuery` 实现分页查询与详情弹窗。所有页面均通过 `<script setup lang="ts">` 单文件组件编写，依赖集中在 `@/hooks/queries` 下的查询 hooks，不直接调用 API，遵循视图层只负责 UI 与状态绑定的职责边界。
