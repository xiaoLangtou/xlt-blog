- Query Hook 统一命名为 `useXxxQuery` / `useXxxMutation`，并通过 `queryKeys.<domain>.<method>(...)` 生成稳定的 queryKey。
- Mutation 中统一在 `onSuccess` 或 `onSettled` 回调里调用 `queryClient.invalidateQueries({ queryKey: queryKeys.<domain>.all })` 来使相关缓存失效。
- Core Hook 通过解构配置对象传入参数（如 `useTable(config)`），并使用泛型 `InferApiParams` / `InferApiResponse` 自动推导 API 参数与响应类型。
- 所有 Hook 返回对象采用语义化命名分组（data/loading/error、pagination、searchParams、refresh* 方法、cacheInfo 等），并在注释中说明各字段用途。
- 需要响应式布尔开关的 Hook 通过 `MaybeRef<boolean>` 参数 + `unref()` 处理，保持与 Vue 3 响应式系统的兼容。
