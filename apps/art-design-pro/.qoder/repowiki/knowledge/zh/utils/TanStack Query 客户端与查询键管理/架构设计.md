模块由三个文件组成：`queryClient.ts` 负责创建并导出 TanStack Vue Query 的 `QueryClient` 实例，内置默认重试策略（4xx 和未授权错误不重试，最多重试 2 次）、staleTime/gcTime 等缓存参数，并提供 `clearQueryCache` 用于登出时清空缓存；`keys.ts` 以嵌套对象形式定义各业务域（auth、menu、system、dept、post、apiManage、logger、cache）的 queryKey 工厂，每个域通过 `all` 基数组派生具体 key，支持带参数的函数式 key 生成以保证类型推导；`index.ts` 作为统一出口，仅重新导出 `createQueryClient`、`queryClient`、`clearQueryCache` 和 `queryKeys`，对外隐藏内部实现细节。依赖方向单向：`queryClient.ts` 依赖 HTTP 层的 `HttpError` 与 `ApiStatus` 判断是否可重试，`keys.ts` 与 `queryClient.ts` 相互独立，均通过 `index.ts` 暴露给上层使用。
