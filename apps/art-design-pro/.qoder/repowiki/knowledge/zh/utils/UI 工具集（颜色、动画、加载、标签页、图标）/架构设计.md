该模块以纯函数式工具库形式组织，每个文件聚焦单一职责并通过 `index.ts` 统一导出对外 API。
- `colors.ts`：核心颜色处理，提供 hex/RGB/RGBA 互转、明暗变调、Element Plus 主题变量注入（`--el-color-primary-*`），依赖 `useSettingStore` 获取暗黑模式状态。
- `animation.ts`：基于 CSS 变量 + View Transition API 的主题切换扩散动画，通过 `toggleTransition` 控制 `.theme-change` class，降级到无动画模式。
- `loading.ts`：单例模式的 ElLoading 封装，自动根据 `document.documentElement.classList.contains('dark')` 适配背景色，返回关闭函数便于 with-pattern 使用。
- `tabs.ts`：声明式配置对象 `TAB_CONFIG`，按 `tab-default`/`tab-card`/`tab-google` 三种样式维护 open/close 的 top 与 height 值，由 `getTabConfig` 提供默认回退。
- `emojo.ts`：HTTP 状态码到表情字符串的映射表，供 ElMessage 组合提示文案。
- `iconify-loader.ts` / `lucide-icons.ts` / `normalizeIcon.ts`：图标生态配套——`normalizeIcon` 将 PascalCase/camelCase 或 `lucide-*` 前缀转为 `lucide:name` Iconify 格式；`lucide-icons.ts` 导出完整图标名列表用于选择器；`iconify-loader.ts` 预留内网离线预加载入口（注释掉的 `addCollection` 调用）。
- 依赖方向：仅向上依赖 hooks（`useTheme`、`useCommon`）、store（`useSettingStore`）、枚举（`SystemThemeEnum`）和第三方组件库（ElLoading、ElMessage），不反向依赖业务模块。
