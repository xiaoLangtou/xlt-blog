模块由三个文件组成清晰的分层：`status.ts` 定义 `ApiStatus` 枚举作为全局状态码常量；`error.ts` 定义 `HttpError` 类及 `handleError`、`showError`、`showSuccess`、`isHttpError` 等错误处理工具；`index.ts` 作为入口创建 Axios 实例并注册请求/响应拦截器，暴露 `get/post/put/del/request` 五个方法。依赖方向单向：`index.ts` → `error.ts` + `status.ts`，`error.ts` 仅依赖 `status.ts` 和国际化 `$t`。核心流程为：请求拦截器自动注入 Authorization Token 与 JSON Content-Type，响应拦截器根据业务 code 判断成功/失败，401 通过防抖定时器触发 `useUserStore().logOut()` 并延迟退出，非 401 错误统一包装为 `HttpError` 并通过 `showError` 提示。
