# 管理端界面收敛设计

## 目标

将媒体存储配置、登录和 Markdown 导入收敛到现有后台的紫灰主题、低圆角卡片和 Element Plus 控件节奏。页面不再各自引入独立视觉语言；导入流程在一个批次完成后锁定，避免重复创建文章。

## 视觉方向：系统优先

采用已确认的“系统优先”方向。全局交互继续使用 `--theme-color` 和 Element Plus 令牌，页面背景、边框、文字和卡片继续使用 `--art-main-bg-color`、`--default-box-color`、`--default-border` 和 Element Plus 文本令牌。

媒体存储页保留“存储类型卡片 + 配置面板”的信息架构，但使用附件库及常规管理页的布局：顶部标题与视图切换、细边框 `ElCard`、标准 `ElForm`、标准按钮组。选中态只使用主题色边框、轻量背景和图标，不再创建独立绿色页面皮肤。卡片和列表都保留选择、编辑、测试、保存和显式设为当前存储操作。

登录页使用干净的双栏布局。左栏只保留品牌、简短欢迎语和主题色的低对比氛围，不再使用多角色图形、网格或大面积高饱和渐变。右栏使用现有 `ElCard`、`ElForm`、`ElInput` 和 `ElButton`，保持表单为主视觉；窄屏仅显示品牌和登录卡片。

## 登录行为

认证请求、会话清理、token 与用户信息写入、成功提示和跳转保持不变。登录页只调整展示层。场景组件接收系统名称和当前焦点/密码/加载状态，但不接触 API、路由或 store。

密码显隐保持 Element Plus 输入框后缀按钮。输入焦点只提供克制的品牌状态反馈；所有动画遵循 `prefers-reduced-motion`。

## 媒体存储行为

`selectedBackend` 继续表示当前正在编辑或测试的后端，`form.active` 继续表示已持久化的上传目标。保存配置不可改变 `form.active`；仅“设为当前存储”可变更活跃后端。测试连接使用未保存草稿。迁移入口仅在已持久化的当前后端为远程存储时出现，并在确认信息中明确该目标。

列表模式展开后直接展示完整配置表单与操作按钮，不要求返回卡片模式。S3 的 endpoint 仅在自定义兼容服务需要时作为必填项；标准云提供商保留可选 endpoint。

## Markdown 导入步骤流

导入弹窗使用 `editing`、`submitting`、`completed` 三个状态：

1. `editing`：步骤 1“选择文件”和步骤 2“导入默认值”可编辑；主按钮为“开始导入”。前端限制最多 50 个 Markdown 文件。
2. `submitting`：步骤 3激活，文件、默认值、关闭操作与提交按钮全部锁定；显示真实上传进度。
3. `completed`：步骤 1 和 2完成，步骤 3显示逐文件结果。文件、默认值和“开始导入”不可再次操作；仅显示“完成并关闭”。关闭事件统一重置文件、默认值、进度和结果，下一次打开才创建新的导入批次。

无论全部成功还是部分失败，当前批次完成后都进入 `completed`，防止同一文件被重复提交。文章列表继续在结果返回后刷新。

## 边界和验证

不修改认证 API、存储 API 或文章导入 API 的请求契约。只在现有 Vue 页面和局部字段组件中修改状态、模板与样式。

验证包括：定向 TypeScript 检查、管理端生产构建、`git diff --check`；并检查导入完成态不存在可点击的重复提交按钮。真实登录、存储测试、迁移和浏览器视觉回归不在本轮自动执行范围。
